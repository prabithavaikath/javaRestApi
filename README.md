# Item Management REST API

A simple RESTful API built with Spring Boot for managing a collection of items (e-commerce style backend).



## 🛠️ Tech Stack
- **Java 17** - Programming language
- **Spring Boot 3.1.0** - Framework for REST APIs
- **Maven** - Dependency management
- **ArrayList** - In-memory data storage

## ✨ Features
- ✅ Add new items with validation
- ✅ Retrieve single item by ID
- ✅ Retrieve all items (bonus endpoint)
- ✅ Input validation for required fields
- ✅ RESTful API design
- ✅ In-memory storage (no database needed)

## 📦 Prerequisites
- Java 17 or higher
- Maven 3.6+
- curl (for testing) or Postman
